# Product Roadmap

## v0.1 — Foundation (Completed)

- [x] POS core: checkout, payment methods, receipt
- [x] Treatment management and therapist assignment
- [x] Booking system with calendar view
- [x] Daily closing and shift management
- [x] Staff lock with countdown timer
- [x] Multi-branch support (BSD, HQ, DPK, CBG)
- [x] User management with PIN authentication
- [x] Service worker for offline resilience
- [x] Audit trail logging

- [x] Master data: Products, Treatments, Users, Branches
- [x] Chart of Accounts (COA) management
- [x] Inventory: stock cards, batch tracking, stock opname
- [x] Finance: journal entries, general ledger
- [x] Period closing and financial period management
- [x] Reporting: sales, inventory, finance exports
- [ ] Accounts Payable workflow
- [ ] Bank reconciliation automation
- [ ] Asset management and depreciation

- [ ] WhatsApp integration for customer notifications

## v0.4 — Operations (Planned)

- [ ] Therapist scheduling and availability

- [ ] Staff commission calculation
